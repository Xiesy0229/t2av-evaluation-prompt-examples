# T2AV 评测题设计参考示例

> **说明：这里的 100 条题目是为展示题目设计与审核方法而创作的参考示例，不代表公司内部真实测评题目、正式题库或实际测评结论。**

本示例以“10 秒、16:9、同时生成画面和声音”为统一条件。每条题目先确定观看目的，再描述一个可在 10 秒内完成的事件，并列出画面、声音和声画关系的可观察检查点。检查点用于审核，不作为生成模型的输入。

## 文件

- `T2AV评测题设计参考示例.xlsx`：100 条示例题目及审核规则。
- `100题.csv`：便于在 GitHub 上直接浏览的题目数据。
- `审核规则.csv`：便于在 GitHub 上直接浏览的审核规则。

## 表格字段

| 字段 | 含义 |
| --- | --- |
| Prompt | 面向视频生成模型的题面。 |
| 观看目的 | 观众看完片段后应获得的主要感受或理解。 |
| 画面／声音／声画关系检查点 | 生成后可逐项观察的证据。 |
| 声画关系类型 | 每题最核心的声音与画面关系。 |
| 主声源呈现 | 主声源在画面内外的呈现方式。 |
| 适用评测项 | 仅列出这道题适用的结果评测维度。 |
| 题面自检 | 对题面完整性、事件顺序及初步去重的检查，不代表模型生成结果或正式入库结论。 |

## 使用边界

- 题目和检查点仅用于演示设计方法，不能据此推断任何公司内部题库、测评流程或模型表现。
- 表中的“通过”仅指题面自检通过；没有生成视频的实测分数，也没有 Badcase 复核结果。
- 使用这些题目开展实际评测时，仍需另行核验题目适用性、重复性、可执行性和生成结果。

## 公开方法参考

题目内容独立创作；审核维度参考了 [AVGen-Bench](https://github.com/microsoft/AVGen-Bench) 和 [T2AV-Compass](https://github.com/NJU-LINK/T2AV-Compass) 等公开项目的思路，未复制其题目。
